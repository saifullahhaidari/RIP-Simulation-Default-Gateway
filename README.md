# RIP Simulation and Default Gateway

## Project Overview
This repository contains a Computer Networks assignment completed using Cisco Packet Tracer at Politeknik Elektronika Negeri Surabaya (PENS).

The project demonstrates network topology design, IP addressing, default gateway configuration, and routing between multiple LANs.

## Network Topology
The network consists of:
- Two routers (Router0 and Router1)
- Three LAN networks
- Three switches
- Three PCs
- A point-to-point connection between the routers

## IP Addressing

| Network | IP Address |
|---|---|
| LAN 1 | 192.168.1.0/24 |
| LAN 2 | 192.168.2.0/24 |
| LAN 5 | 192.168.5.0/24 |
| Router Link | 192.168.3.240/30 |

## Routing Configuration
The provided configuration uses:
- Static routing on Router1
- A default route on Router0
- Default gateways for end devices

**Note:** The submitted configuration demonstrates static routing and default gateway concepts. It does not implement dynamic RIP routing.
